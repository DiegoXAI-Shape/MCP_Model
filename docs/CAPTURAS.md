# Capturas para el README

Guardar los PNG en `docs/img/` con estos nombres:

| Archivo | Cómo obtenerlo |
|---|---|
| `inspector-tools.png` | `mcp dev server.py` → en el Inspector, pestaña **Tools** → **List Tools** (se ven las 7) |
| `inspector-call.png` | En el Inspector, ejecutar `list_accounts` con `bucket = 90+`, `limite = 5` y capturar el resultado |
| `ui-resumen.png` | Abrir `out/01-*.html` (resumen ejecutivo) en el navegador |
| `ui-aging.png` | Abrir `out/02-*.html` (aging) en el navegador |
| `galeria.png` | Abrir `out/index.html` en el navegador |

Sugerencia: recortar a ventana, sin barra del navegador, ancho ~1200 px.
